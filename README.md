# MangoLoads

A responsive personal portfolio for **Batmancpu**, built as a static site and hosted with GitHub Pages.

## Live website

Once GitHub Pages is enabled for this repository:

- Project URL: https://batmancpu.github.io/mangoloads/

## Design

- Dark Liquid Glass visual language with an optional light theme
- Responsive layouts for phones, tablets and desktop
- Accessible navigation, project search and category filters
- No build step, package manager, tracking scripts or third-party JavaScript dependencies
- Static HTML, CSS and JavaScript only

## Projects

The portfolio distinguishes original work and experiments from community forks and release archives. Third-party projects, trademarks and assets remain the property of their respective authors. Private repositories are intentionally excluded.

To update project details, edit the `projects` array in `index.html`. To update the featured project, edit the Featured section in the same file.

## Publishing

In GitHub, open **Settings → Pages** and set:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

Save the settings. GitHub Pages will publish the root `index.html` after the commit is processed.
